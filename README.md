# 📌 코드 컨벤션

## 1. 커밋 규칙

이슈 번호를 앞에 붙여 커밋 메시지를 작성합니다.

```bash
git commit -m "#이슈번호 수정내용"
```

> 예시: `git commit -m "#12 수정완료"`

---

## 2. 브랜치명 규칙

`food/본인이니셜_0x` 형식으로 브랜치를 생성합니다.

```bash
git branch food/이니셜_0x
git switch food/이니셜_0x
```

> 예시: `food/AJM_01`

---

## 3. PR 코멘트 규칙

- 수정한 내용을 **구체적으로** 명시합니다.
- 어떤 파일을 어떻게 변경했는지 확실히 언급합니다.

---

## 4. 폴더 / 파일명 규칙

`이니셜_순번` 형식으로 파일을 생성합니다.

```bash
nano 이니셜_01.md
```

> 예시: `AJM_01.md`, `KGD_02.md`
